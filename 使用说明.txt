TO YY · 月亮小站 —— 使用说明（2026-10 双版更新）
════════════════════════════════════════════════

【怎么改照片的标题和说明 —— 最简单】
用记事本打开 moon-site\captions.js
每一行是一张照片：
    "1":  ["标题", "一句话说明"],
只改引号里的字，别动引号、逗号、大括号。
照片号对应 assets 里的文件名：1 就是 1.jpg。
改完保存 → 网页按 F5 刷新 → 立即生效。
（直接双击 index.html 打开也一样有效；
 哪一整行删掉，就会自动用回默认文字）

【怎么打开】
推荐：双击「启动小站.bat」
      → 自动开一个小服务器并在浏览器打开网站
      → 手账功能完整可用
      → 停止方法：关掉那个最小化的 MoonSiteServer 黑窗口

也可以：直接双击 index.html（不需要联网）
      → 照片、信、月记、愿望、信箱都正常
      → 只有「手账」读不到文件夹，会给出提示

【七个页签】
结缘（进门第一眼的信）｜回忆（照片 I–X）｜时序（时间线）
手账（你的 .txt 手账本）｜月记（天数 + 今晚月相）
愿望（可打勾的清单）｜信箱（悄悄话，存在本地浏览器）

【怎么改月记页上的文字】
都在 timeline.js 最下面的 window.MOON_TEXT 里：
  title   大标题「月亮日记」
  en      标题旁的英文小字
  label   「自 2026.9.2 ____」最后那截字
  unit    大数字旁边的单位字
  tonight 月相那行开头的「今晚的月亮」
  tiny    面板最下面的小字
  phases  八种月相的名字(name)和诗句(poem)，顺序别换
只改冒号后引号里的字；哪行删掉就用回默认。改完 F5。

【月记和手账的区别 —— 一句话】
· 月记 = 月亮替你更新的面板：认识天数 + 今晚真实月相，
  每晚自动变，你永远不用动，也不能往里写字
· 手账 = 你自己更新的本子：stories 文件夹丢 .txt 就行
  想按日期写日记，就把文件名写成「2026-10-28 ……」即可

【月记的天数和月相 —— 全自动，不用管】
· 天数 = 今天 − 起算日，每次打开自动重算
· 月相 = 按真实天文周期算出今晚的月亮，每晚不同
· 起算日在 timeline.js 最下面：
  window.MOON_ANCHOR = "2026.9.2"
  只改引号里的日期，前面的 window.MOON_ANCHOR = 别动

【怎么写手账 —— 重点】
1. 打开 moon-site\stories 文件夹
2. 新建一个 .txt 文件，文件名就是标题
   例如「2026-10-27 今天月亮很圆.txt」
3. 用记事本随便写，保存（UTF-8 或 ANSI 都行）
4. 回到网站「手账」页，点「重新读取」
→ 完全不用找我改网站！

【信箱的信件怎么带给她 —— 重要】
信箱里的悄悄话默认只存在你自己的浏览器里。
打包送给她之前，多做一步：
1. 打开网站「信箱」页，点下面的「导出信件」
2. 浏览器会下载一个 moon-letters.txt
3. 把它从「下载」文件夹挪进 moon-site 文件夹（和 index.html 放一起）
4. 再压缩 moon-site 发给她
她打开信箱页时，网站会自动读取这个文件，你的悄悄话就都出现了。
她那边写的信也可以同样「导出」一份带回给你，你用「导入信件」就能看。
（moon-letters.txt 本身也能直接用记事本打开看/改）

【怎么送给她】
把整个 moon-site 文件夹压缩成 zip 发过去即可（记得先按上面导出信件）。
她的电脑上：解压 → 双击 启动小站.bat（需要装 Python）
或双击 index.html（不装 Python 也能看，只是手账和信件文件读不了）。
想要她手机随时能看的话，可以免费部署到
GitHub Pages / Vercel / Netlify —— 需要时找我帮忙。

【怎么加时序章节（可补记以前的事）】
用记事本打开 moon-site\timeline.js
每一行就是一个章节，格式：
    "日期 | 标题 | 一段话",
★ 日期写成真实日期（如 2026.10.20），
  章节会自动标出「第 N 天」的金牌子，
  天数每晚自己重算，永远不用你手动更新
★ 写成「2026 · 盛夏」这种模糊日期也行，只是没有天数牌
补记前几天的事 = 把新行插到时间顺序该在的位置；
记以后的事 = 直接加一行，日子到了自然对上。
加完保存 → 网页 F5 刷新。

【月记是怎么更新的 —— 不用管】
· 天数：每次打开网页自动重新计算（从起算日到今天）
· 月相：按真实天文周期算出「今晚」的月亮，自动更新
· 唯一可能想改的：起算日期。在 timeline.js 最下面
  把 window.MOON_ANCHOR = "2026.9.2" 里的日期改掉即可

【怎么改网站内容】
用记事本/VSCode 打开 index.html，搜索「EDIT」：
  EDIT 1  结缘信正文
  EDIT 2  照片区（加照片：图放 assets/，复制一个 <figure class="polar"> 块）
  EDIT 5  默认愿望清单
照片说明 → captions.js；时序章节 / 起算日 → timeline.js
（这三个 js 都可以直接记事本改，不用碰 index.html）

【数据存在哪】
· 手账 = stories 文件夹里的真实 .txt 文件，跟着文件夹走
· 愿望勾选 / 信箱悄悄话 = 本机浏览器 localStorage，
  换浏览器或换电脑不共享；送人前记得先删掉自己的测试内容

【小彩蛋】
· 进站开场：先是一弯远远的月 → 点它 → 由远及近变满月 → 结缘信显现
  同一个浏览器只播第一次；右下角「先直接进入」可跳过；
  想重新看：关掉所有标签页再重新打开即可
· 进站后点月亮 → 流星雨
· 进站后点小狗 → 它说一句话
· 照片点开大图，← → 方向键翻页
